Juegos Torrent v2.7.86 — Card y Flyer

INSTALACIÓN
Usar una copia de la carpeta actual. Añadir el nuevo .py conservando recursos, tutoriales y demás archivos. Ejecutar Juegos_Torrent_v2_7_86_Promo_Card_Flyer.py.
Este paquete contiene código y configuración; no incluye los recursos gráficos de tu instalación.

PUBLICAR UNA PROMOCIÓN
1. Crear la carpeta promociones en juegos-torrent-progama y subir una imagen JPG, PNG o WebP.
2. Copiar uno de los JSON de ejemplo a promociones.json en ese repositorio.
3. Ajustar juego para que coincida con el título del catálogo, titulo, mensaje e imagen.
4. Elegir formato: card o flyer. Si se omite, se usa card.
5. Usar un ID nuevo en cada campaña o prueba. Los ID vistos no se repiten.

imagen admite una ruta relativa al promociones.json remoto, por ejemplo promociones/atomic_card.jpg, o una URL HTTPS completa. Puede omitirse o estar vacía. No es una ruta del disco de Windows.
Card: imagen vertical o portada; Flyer: imagen panorámica. Se conserva la imagen completa, sin recortarla. Recomendamos mensaje breve (1–3 frases). El título y el mensaje se muestran debajo de la imagen; pueden estar vacíos si el flyer ya tiene esos textos. El nombre del juego permanece visible.
Límite de descarga: 8 MiB; imágenes de hasta 20 megapíxeles. Caché por URL e ID. Si cambia la imagen, publicar un ID nuevo.

FUNCIONAMIENTO
Imagen descargada en segundo plano. Si falla, portada local o fondo alternativo. Una campaña por ID, cierre inmediato, sin bloqueo del catálogo y sin navegación pendiente. Esquinas transparentes en Windows cuando Tk admite transparentcolor. En otras plataformas se conserva un fondo rectangular.

VERIFICACIÓN
Código compilado y validación de formato/configuración comprobada. Pendiente de prueba visual y funcional en Windows, incluidos escalado DPI y transparencias.
